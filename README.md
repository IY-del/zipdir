# zipdir

`zipdir` は、Git の `.gitignore` に似た直感的なルール定義に加えて、階層的スコープカスケード、スマートな救出・リマップ（階層死守・亡命ルート・パス再配置）、および不要ディレクトリの先行枝刈り最適化を備えたディレクトリ・パッケージングツールです。

---

## 1. 特徴

1. **Python の LEGB 則に倣った 4 階層カスケード解決**
   - 外側から内側、そして実行時引数へと階層的にルールを評価・オーバーライドします。
   - プリセット（Built-in）→ ルート（Global）→ サブディレクトリ（Local）→ コマンド引数（Args）の順に優先度が上がります。

1. **高度な救出・リマップ記法 (Rescue & Remap)**
   - ディレクトリ全体を除外した上で、特定の成果物（PDF やドキュメントなど）のみを安全に救出してアーカイブに含めることができます。
   - 元の階層を死守して収録する `./!` や、親ディレクトリへリフトする亡命ルート `?/!`（単に `!` でも可）、任意のディレクトリへ移動する `{to}!`、救出を打ち消す再除外 `!!` に対応しています。

1. **局所スコープと相対・絶対パス記法**
   - サブディレクトリに置かれた `.zipignore` のルールは、そのサブディレクトリ配下にのみ局所適用されます。
   - 救出先リマップは、先頭に `/` がない場合はそのスコープからの相対パス、先頭に `/` がある場合はアーカイブ全体（ルート）基準の絶対パスとして解釈されます。

1. **非貪欲枝刈り (Non-Greedy Pruning)**
   - ディレクトリ走査の前にツリー全体の局所 `.zipignore` を先行探索し、配下に有効な救出ルールがあるディレクトリは誤って除外枝刈り（Prune）されないように保護します。

1. **使いやすい既定値とオプション**
   - デフォルトの出力ファイル名は `<ディレクトリ名>.zip` です。
   - `-t` / `--timestamp` フラグを指定することで、`<ディレクトリ名>_<YYYYMMDD_HHMMSS>.zip` の形式でタイムスタンプを付与できます。

## 2. 構文リファレンス

ルールは各行に記述し、`#` で始まる行はコメントとして無視されます。

| 記法 | 種別 | 説明 |
| :--- | :--- | :--- |
| `out/` | 除外 (EXCLUDE) | `out` ディレクトリおよびその配下をすべて除外 |
| `*.log` | 除外 (EXCLUDE) | 拡張子が `.log` のファイルをすべて除外 |
| `!out/*.pdf` | 亡命救出 (RESCUE, `?`) | `out` は除外するが、配下の PDF を除外元ディレクトリの親へリフトして救出 |
| `./!out/*.pdf` | 階層死守 (RESCUE, `./`) | `out` は除外するが、`out/` 配下の階層構造を完全に維持したまま PDF を救出 |
| `dist!out/*.pdf` | スコープ相対リマップ | その `.zipignore` の配置階層を基準として `dist/` 配下へ救出・配置 |
| `/dist!out/*.pdf` | ルート絶対リマップ | アーカイブの全体ルートを基準として `dist/` 配下へ救出・配置 |
| `!dist!out/*.pdf` | 救出打消 (REDELETE) | 先行する `dist!out/*.pdf` による救出設定のみをピンポイントで打ち消して再除外 |
| `!!out/*.pdf` | 完全再除外 (REDELETE) | 先行する救出設定をすべて打ち消し、再び除外対象へ戻す |

---

## 3. ルール解決の優先度 (4 階層カスケード)

複数のルール間で競合が発生した場合、以下の優先度に従って解決されます（同一スコープ内では後に定義されたルールが優先されます）。

1. **プリセット (Tier 1: Built-in)**
   - `presets/` ディレクトリに定義された共有ルール。
   - デフォルトで `clean` プリセットが読み込まれます。

1. **ルート `.zipignore` (Tier 2: Global)**
   - アーカイブ対象ディレクトリ直下の `.zipignore`。
   - プロジェクト全体の大域ルールとして適用されます。

1. **サブディレクトリ `.zipignore` (Tier 3: Local / Enclosing)**
   - サブディレクトリ内に配置された局所ルール。
   - 階層が深いサブディレクトリのルールほど、より浅い親ディレクトリのルールを局所的に上書きします。

1. **コマンドライン引数 (Tier 4: CLI Overrides)**
   - `-x` / `--exclude`、`-r` / `--rule` など、CLI 実行時に渡された最優先オプション。

## 4. プリセット機能

プリセットファイル（`*.zipignore`）を定義することで、よく使う除外・救出パターンをテンプレート化できます。

### 標準プリセット

- **`clean`**:
  - OS メタデータ（`.DS_Store`、`Thumbs.db` 等）、バージョン管理（`.git`、`.svn` 等）、エディタ設定（`.vscode`、`.idea` 等）、Python/Node キャッシュ（`__pycache__`、`node_modules` 等）、環境変数・シークレット（`.env` 等）、および `.zipignore` 自身を除外。
- **`report`**:
  - `clean` を継承し、`out/` を除外した上で、ビルドされた `out/*.pdf` をアーカイブ直下に亡命リフトして収録。

### プリセットの継承

プリセットファイルの冒頭に `# inherit: <親プリセット名>` を記述することで、既存プリセットのルールを継承・拡張できます。

```text
# inherit: clean
# description: Custom distribution preset
build/
dist!build/*.tar.gz
```

## 5. 使い方

### 基本的なコマンド

```sh
# カレントディレクトリを ../<dir>.zip にアーカイブ
zipdir

# タイムスタンプ付きのアーカイブ (../<dir>_<timestamp>.zip) を作成
zipdir -t

# 特定のディレクトリをパッケージ
zipdir path/to/my_project

# 出力先パスを指定
zipdir path/to/my_project -o /tmp/custom.zip
zipdir path/to/my_project /tmp/custom.zip

# 既存ファイルを上書き
zipdir -f

# プリセットを指定
zipdir --preset report

# プリセット一覧とルール内容を表示
zipdir --list-presets

# 実際に ZIP を生成せず、収録予定メンバーとリマップを確認
zipdir --dry-run

# 個別ルールの追加指定
zipdir -x "*.bak" -r "!dist!*.csv"
```

### CLI オプション一覧

- `-t, --timestamp`: 出力ファイル名にタイムスタンプ（`_YYYYMMDD_HHMMSS`）を付与（既定: `False`）
- `--preset <name>`: 使用するプリセット名を指定（既定: `clean`）
- `--list-presets`: 利用可能なプリセット一覧を表示して終了
- `-x, --exclude <pattern>`: 追加の除外パターンを指定（複数指定可）
- `-r, --rule <rule>`: 追加のルール（救出・リマップ等）を指定（複数指定可）
- `-k, --keep <pattern>`: プリセットのルールから特定の完全一致パターンを削除（複数指定可）
- `--no-default-rules`: プリセットのルールを一切適用しない
- `-o, --output <path>`: 出力ファイル名または出力先ディレクトリを指定
- `--name <name>`: アーカイブのルートディレクトリ名および既定のプレフィックスを指定
- `--flat`: ZIP 内部に最上位の親ディレクトリを含めず、直下に展開されるようにフラット化
- `--compression <0..9>`: 圧縮レベルを指定（0: 無圧縮、1〜9: デフレート、既定: 6）
- `-f, --force`: 同名ファイルが存在する場合に上書き
- `-v, --verbose`: 救出・除外されたファイルの詳細情報を表示
- `--dry-run`: アーカイブを作成せず、結果のプレビューのみを表示
